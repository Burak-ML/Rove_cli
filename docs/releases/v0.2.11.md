## What's new

**A new Agent space.** Agents now work like a messenger: pinned agents, the last message in each row, bubbles and a one-line message box. An agent's logo sleeps until it works, then its eyes open and it thinks where you can see it.

**Agents are simple to make.** A new agent is a name and a logo. The name says what it is for; if it does not, the agent asks you first, with answers you can click.

**Agents talk, code stays in Code.** Agents read and answer but do not write code or change files. When you ask, they can message each other and create new agents.

**More ways to connect.**
- OpenCode: its free models work with no account
- Claude Code with a setup token, Codex through your browser
- Custom providers live in Add, and their models are read from the address
- The first provider you connect becomes the default

**A calmer app.** A neutral default theme, simpler session and model pickers, a Models window to keep your list short, and reworked Servers and Providers screens.

## Removed

The team board and everything behind it: background tasks and their reviews, agent notes, monitors, schedules, watches and handoffs. Existing data stays in the database but is no longer read. Agents no longer use the catalog's characters; Teamwork still does.

## Install

**macOS / Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/Burak-ML/Rove_cli/main/install.sh | sh
```

**Windows (PowerShell)**

```powershell
Set-ExecutionPolicy -Scope Process Bypass
iwr https://raw.githubusercontent.com/Burak-ML/Rove_cli/main/install-windows.ps1 | iex
```

The installer verifies binaries against `SHA256SUMS`.
